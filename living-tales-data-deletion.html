Living Tales - Data Deletion

Living Tales does not require users to create an account. User profiles and story progress are stored locally on the user's device.

How to delete your data

To permanently delete all Living Tales data from your device:

  1. Open your Android device Settings
  2. Select Apps
  3. Select Living Tales
  4. Select Storage
  5. Select Clear Data or Clear Storage
Warning: Clearing app data permanently deletes your local Living Tales data. This action cannot be undone.

Data that will be deleted

  • User profiles
  • Stories
  • Characters
  • World settings
  • Story progress
  • Decision history
  • Journal entries
  • Saved choices
  • Application settings

Data retention

Living Tales does not retain deleted local app data. Once app data is cleared from the device, the data is permanently removed.

Accounts and server data

Living Tales does not provide user accounts and does not store user profiles on external servers.
